# ASPIEF
Asociación Peruana de Investigadores y Estudiantes de Filosofía

Sitio: https://lufer19.github.io/aspief/

- `index.html`: portada (cursos y talleres, videos, noticias, redes). La configuración está al final del archivo, en el bloque `CFG`.
- `aspief.css` y `aspief-layout.js`: cabecera y pie compartidos por todas las páginas internas.
- Páginas de Ágora Peruana: aprender, filosofos, glosario, linea-tiempo, ejercicios, recursos, articulos, investigar, comunidad, podcast.

Contacto: aspief.pe@gmail.com
